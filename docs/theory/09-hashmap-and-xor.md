# HashMap — объяснение с нуля

Забудь на минуту equals/hashCode и Big-O. Сначала смысл.

---

## 1. Зачем он нужен одной фразой

Тебе нужно хранить пары «это → вот это» и быстро спрашивать: «что лежит по вот этому ключу?»

Примеры из жизни:
- имя студента → оценка
- номер телефона → имя владельца
- число из массива → сколько раз встретилось

Массив так не умеет удобно: индекс только 0,1,2,3…  
А ключ в HashMap может быть чем угодно подходящим: `String`, `Integer`, …

---

## 2. Две колонки: ключ и значение

Представь таблицу:

| ключ (key) | значение (value) |
|------------|------------------|
| "Anna"     | 5                |
| "Bob"      | 4                |
| "Clara"    | 5                |

- **Ключ** — по чему ищем (уникальная «этикетка» в этой таблице; один ключ — одно значение).
- **Значение** — что храним по этой этикетке.

В Java:

```java
Map<String, Integer> grades = new HashMap<>();
```

Читай так: «Map из String-ключей в Integer-значения».  
`HashMap` — конкретная реализация этой идеи.

Почему слева `Map`, справа `HashMap`:
- `Map` — «тип договора» (умею put/get),
- `HashMap` — «как именно устроено внутри».
Пока просто пиши как в примере.

---

## 3. Три действия, которые нужны всегда

### Положить / обновить — `put`

```java
grades.put("Anna", 5);
grades.put("Bob", 4);
grades.put("Anna", 3); // тот же ключ — старое значение 5 ЗАМЕНИЛОСЬ на 3
```

Ключ `"Anna"` по-прежнему один. Значение теперь 3.

### Достать — `get`

```java
Integer g = grades.get("Bob"); // 4
Integer x = grades.get("Unknown"); // null — такого ключа нет
```

`null` значит «не нашли», а не число 0.

### Есть ли ключ — `containsKey`

```java
if (grades.containsKey("Anna")) {
    // да, Anna есть в таблице
}
```

## 4. Живой пример по шагам (оценки)

```java
import java.util.HashMap;
import java.util.Map;

public class HashMapDemo {
    public static void main(String[] args) {
        Map<String, Integer> grades = new HashMap<>();

        // шаг 1: пустая таблица
        System.out.println(grades.size()); // 0

        // шаг 2: добавили двух людей
        grades.put("Anna", 5);
        grades.put("Bob", 4);
        System.out.println(grades.get("Anna")); // 5

        // шаг 3: исправили оценку Anna
        grades.put("Anna", 5); // можно снова 5
        grades.put("Anna", 4); // теперь 4
        System.out.println(grades.get("Anna")); // 4

        // шаг 4: кого-то нет
        System.out.println(grades.get("Chris")); // null
        System.out.println(grades.containsKey("Chris")); // false
    }
}
```

Запусти это у себя (можешь скопировать в `labs/oop/HashMapDemo.java`), посмотри вывод. Так HashMap «ощущается».

## 5. Самое нужное в задачах: счётчик

Задача: для каждого числа в массиве посчитать, сколько раз оно встретилось.

Массив: `[2, 2, 1]`

Хотим таблицу:

| ключ | значение (сколько раз) |
|------|-------------------------|
| 2    | 2                       |
| 1    | 1                       |

Код идеи:

```java
Map<Integer, Integer> freq = new HashMap<>();

for (int n : nums) {
    // сколько уже было этого n? если не было — считаем 0
    int already = freq.getOrDefault(n, 0);
    // записываем на 1 больше
    freq.put(n, already + 1);
}
```

`getOrDefault(n, 0)` читается так:  
«дай значение по ключу `n`; если ключа нет — верни 0».

После цикла:
- `freq.get(2)` → 2  
- `freq.get(1)` → 1  

Для Single Number ищешь ключ, у которого значение **1**.

---

## 6. Как пройтись по всей таблице

```java
for (Map.Entry<Integer, Integer> entry : freq.entrySet()) {
    Integer key = entry.getKey();     // число
    Integer value = entry.getValue(); // сколько раз
    System.out.println(key + " встречается " + value + " раз");
}
```

`entry` — одна строка таблицы (пара ключ+значение).

---

## 7. Частые ошибки новичков

1. **Ждать `get` числом `0`, когда ключа нет** — будет `null`, не 0. Поэтому `getOrDefault`.  
2. **Путать ключ и значение** — ключ это «по чему ищем», значение «что храним».  
3. **Думать, что порядок for-each как в массиве** — у HashMap порядок может быть любым.  
4. **Писать `Map<int, int>`** — нельзя, только `Integer` (объектные типы).

---

## 8. Связь с твоей бонусной задачей

Single Number словами через HashMap:

1. Создай `Map<Integer, Integer>`.  
2. Пройди массив, для каждого числа увеличь счётчик.  
3. Пройди пары в map, найди число со счётчиком 1, верни его.

XOR — это другой, более хитрый способ; к HashMap он не обязателен. Сначала закрой задачу map’ом.
