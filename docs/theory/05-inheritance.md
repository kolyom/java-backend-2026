# Тема 3 — Наследование

## Идея одной фразой

Новый класс = «старый класс + дополнения/изменения».  
Не копируй поля и методы — **расширь** базовый тип.

## Зачем

Общий код в одном месте. `SavingsAccount` и `CreditAccount` оба счета — общее в `BankAccount`, различия в наследниках.

## Словарь

| Слово | Смысл |
|--------|--------|
| суперкласс / родитель | базовый класс (`BankAccount`) |
| подкласс / наследник | `extends BankAccount` |
| `extends` | «является разновидностью» |
| `@Override` | переопределили метод родителя |
| `super` | обращение к родителю (конструктор / метод) |

## Важно

- В Java **один** родитель у класса (`extends` только один раз).
- Наследник **является** родителем: `BankAccount a = new SavingsAccount(...)` — допустимо (полиморфизм разберём отдельно).
- `private` поля родителя наследник **напрямую не видит** — только через методы/`protected` (пока пользуйся публичными/package методами родителя).

## Пример идеи (не копируй как задание)

Родитель умеет `deposit` / `withdraw`.  
Наследник `SavingsAccount` добавляет поле «процент» и метод `applyInterest()`.

## Упражнение

Файл: `labs/oop/SavingsAccount.java`

1. Класс `SavingsAccount extends BankAccount`  
   (тот же пакет/папка, что `BankAccount` — уже ок).
2. Поле `double annualRate` (например 0.05 = 5% годовых) — через конструктор.
3. Конструктор: принимает `id`, стартовый баланс, `annualRate`.  
   Баланс/id должны уйти в родителя через `super(...)`.
4. Метод `void applyInterest()` — увеличить баланс на `balance * annualRate`.  
   Баланс private у родителя — значит либо добавь в `BankAccount` метод вроде `protected`/`public` для изменения/чтения, либо `deposit` суммы процентов, посчитанной через `getBalanceKopecks()`.
5. В `main` у `SavingsAccount`: создай счёт, `deposit`, `applyInterest`, `print`.

Критерий: после процентов баланс больше, чем до.

Готовых решений нет. `done` / `pick` (словами).
