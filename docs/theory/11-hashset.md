# HashSet — с нуля

Связь с HashMap и задачей Contains Duplicate.

---

## 1. Что это одной фразой

`HashSet` — **множество**: набор значений **без дубликатов**.  
Порядок не важен. Вопрос, на который он отвечает лучше всего: **«этот элемент уже был?»**

Аналогия: список гостей на входе. Каждый человек один раз. Кто уже прошёл — второй раз не записываем / сразу видно, что повтор.

---

## 2. Чем отличается от HashMap и List

| | List (ArrayList) | HashMap | HashSet |
|--|------------------|---------|---------|
| Что хранит | элементы по индексу 0,1,2… | пары ключ→значение | только значения (элементы) |
| Дубликаты | можно | ключи уникальны | элементы уникальны |
| Главный вопрос | «что под номером i?» | «что по ключу k?» | «есть ли уже x?» |

Внутри HashSet по сути как HashMap, у которого есть только ключи (значения-заглушки). Поэтому снова важны `equals`/`hashCode` для своих классов. Для `Integer` / `String` всё уже сделано.

---

## 3. Создание и основные методы

```java
import java.util.HashSet;
import java.util.Set;

Set<Integer> seen = new HashSet<>();

seen.add(5);              // положили; вернёт true (раньше не было)
seen.add(5);              // второй раз; вернёт false (уже было), в сете по-прежнему один 5

boolean has = seen.contains(5); // true — «уже видели?»
int n = seen.size();            // сколько уникальных
seen.remove(5);
boolean empty = seen.isEmpty();
```

Слева часто пишут `Set`, справа `new HashSet<>()` — как `Map` / `HashMap`.

---

## 4. `add` возвращает boolean — это важно

```java
if (!seen.add(n)) {
    // add вернул false → n УЖЕ был в сете → нашли дубликат
}
```

Эквивалент длиннее:

```java
if (seen.contains(n)) {
    // дубликат
} else {
    seen.add(n);
}
```

Оба варианта ок для Contains Duplicate.

---

## 5. Живой пример

Массив: `[1, 2, 3, 1]`

```text
шаг 1: 1 — не было → кладём в set  {1}
шаг 2: 2 — не было → {1,2}
шаг 3: 3 — не было → {1,2,3}
шаг 4: 1 — УЖЕ есть → дубликат → true
```

Массив: `[1, 2, 3, 4]` — дошли до конца, ни разу «уже есть» → false.

---

## 6. Зачем не два цикла

Два цикла: сравниваешь каждый с каждым → медленно на больших n.  
HashSet: один проход, проверка `contains`/`add` в среднем быстро.

Память: Set занимает место под уникальные элементы — за скорость платим памятью.

---

## 7. Частые ошибки

1. Путать с `HashMap` — в Set нет `put(key, value)`, есть `add(element)`.  
2. Ждать порядок как в массиве — HashSet порядок не обещает.  
3. Для своих классов-элементов забыть `equals`/`hashCode` (как в лабе AccountId).
