# Двоичная система с нуля + Number of 1 Bits

Тебе **не нужно** в коде руками «переводить в двоичную» и получать строку `"1011"`.  
Компьютер **уже** хранит `int` в двоичном виде.  
Код только **спрашивает** у числа: «младший бит какой?» и «сдвинь биты».

Но чтобы это не было магией — ниже вся база.

---

## 1. Зачем вообще двоичная

В электрике удобно два состояния: есть сигнал / нет → **1** и **0**.  
Любое число в памяти — цепочка таких нулей и единиц.

Десятичная (привычная нам) — для людей.  
Двоичная — для машины.  
Задача Number of 1 Bits как раз про «заглянуть» в машинную запись.

---

## 2. Десятичная система (опора)

Основание **10**, цифры 0–9.

Число **275**:

```text
2×100 + 7×10 + 5×1 = 275
```

Веса справа налево: 1, 10, 100, 1000, … (степени десятки).

---

## 3. Двоичная система

Основание **2**, цифры только **0** и **1**.

Веса справа налево: 1, 2, 4, 8, 16, 32, 64, 128, … (степени двойки).

```text
вес:   ...  128  64  32  16   8   4   2   1
```

Если в разряде **1** — этот вес входит в сумму.  
Если **0** — не входит.

### Пример: что значит 1011

```text
веса:    8  4  2  1
биты:    1  0  1  1
         │  │  │  │
         8  0  2  1

8+2+1 = 11
```

Запись `1011` — это и есть «двоичный вид» числа 11.

---

## 4. Как ПЕРЕВЕСТИ десятичное → двоичное (руками)

Способ **делением на 2** (самый простой для запоминания).

Правило:
1. Дели число на 2.
2. Остаток (0 или 1) — это очередной бит **справа налево** (сначала получишь младший бит).
3. Частное снова дели на 2.
4. Пока не станет 0.
5. Остатки снизу вверх / с конца = двоичная запись.

### Пример: 11 → ?

```text
11 ÷ 2 = 5  остаток 1   ← младший бит (самый правый)
 5 ÷ 2 = 2  остаток 1
 2 ÷ 2 = 1  остаток 0
 1 ÷ 2 = 0  остаток 1   ← старший из этих четырёх
```

Остатки **снизу вверх**: **1 0 1 1** → `1011`.

Проверка: 8+0+2+1 = 11. Ок.

### Ещё пример: 13 → ?

```text
13 ÷ 2 = 6  ост. 1
 6 ÷ 2 = 3  ост. 0
 3 ÷ 2 = 1  ост. 1
 1 ÷ 2 = 0  ост. 1
```

Снизу вверх: **1101** = 8+4+0+1 = 13.

### Пример: 8 → ?

```text
8 ÷ 2 = 4  ост. 0
4 ÷ 2 = 2  ост. 0
2 ÷ 2 = 1  ост. 0
1 ÷ 2 = 0  ост. 1
```

→ **1000** (одна единица) — поэтому в задаче ответ для 8 = **1**.

---

## 5. Как перевести двоичное → десятичное

Справа налево веса 1,2,4,8,…  
Сложи веса, где стоит 1.

`1101` = 1+0+4+8 = 13.

---

## 6. Что такое «младший бит»

Самый **правый** бит.  
Он отвечает на вопрос: число **чётное или нечётное**?

- чётное → младший бит **0**
- нечётное → младший бит **1**

Примеры:
- 11 нечётное → младший = 1  
- 10 чётное → младший = 0  

В коде это:
- `n % 2`  → 0 или 1  
- или `n & 1` → 0 или 1 (побитово, то же для положительных)

---

## 7. Что делает деление на 2 с битами

`n / 2` (целая часть) = «выбросили младший бит, все остальные сдвинулись вправо».

```text
11 = 1011
 ÷2 → 5 =  101     (правая 1 исчезла)
 ÷2 → 2 =   10
 ÷2 → 1 =    1
 ÷2 → 0
```

Это и есть способ **по очереди посмотреть все биты**, не рисуя строку.

---

## 8. Связь с задачей Number of 1 Bits

Задача: сколько раз в двоичной записи встречается **1**.

Ты **не пишешь** перевод в строку `"1011"`.  
Ты делаешь цикл:

```text
count = 0
пока n ещё не 0:
    если младший бит == 1 → count++
    n = n / 2          (или сдвиг вправо)
вернуть count
```

Для 11:

| n | младший | count | n после /2 |
|---|---------|-------|------------|
| 11 | 1 | 1 | 5 |
| 5 | 1 | 2 | 2 |
| 2 | 0 | 2 | 1 |
| 1 | 1 | 3 | 0 |
| 0 | стоп | **3** | |

Ответ 3 — без единой строки и без «перевода» вручную в уме на каждом тесте.  
Деление само «идёт» по битам.

---

## 9. Зачем тогда теория перевода руками?

Чтобы понимать:
- откуда берётся `1011`
- почему `% 2` = младший бит
- почему `/ 2` открывает следующий бит

В программе перевод «в столбик» не нужен — его заменяет цикл.

---

## 10. Побитовые операции (кратко, пригодятся)

Можно не использовать в первом решении, но полезно знать:

| запись | смысл |
|--------|--------|
| `n & 1` | младший бит (0 или 1) |
| `n >> 1` | сдвиг вправо ≈ `/2` для положительных |
| `n >>> 1` | логический сдвиг (в Java часто для битовых задач) |
| `n & (n-1)` | убрать одну единицу (продвинутый трюк) |

Первое решение спокойно пиши через `% 2` и `/ 2` — так понятнее с нуля.

---

## 11. Java: тип int — 32 бита

Любой `int` — это **ровно 32** двоичных разряда (часть слева — нули).

`11` в памяти примерно:
```text
0000 0000 0000 0000 0000 0000 0000 1011
```

Нули слева на ответ не влияют: единиц всё равно три.

## 12. Тренировка руками (5 минут)

Переведи делением на 2 и посчитай число единиц:

1. `6`  
2. `7`  
3. `16`  

Ответы:
1. `110` → единиц 2  
2. `111` → единиц 3  
3. `10000` → единиц 1  

---

## 13. План кода для NumberOf1Bits

1. `int count = 0;`
2. цикл `while (n != 0)` (или пока есть что смотреть)
3. если `n % 2 == 1` → `count++`
4. `n = n / 2;`
5. `return count;`

Отдельно подумай про `n == 0` → сразу 0.
