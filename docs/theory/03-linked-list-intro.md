# Связный список — подробный разбор

## 1. Зачем вообще не массив

**Массив** в Java: `int[] a = {1, 2, 3}`  
- Элементы лежат **подряд** в памяти  
- Сразу можешь взять `a[2]`  
- Размер фиксирован (обычный массив)  
- Вставка в середину = сдвигать кучу элементов  

**Связный список** — другая договорённость:
- Каждый элемент — **отдельный объект** (узел)
- Узел знает только: своё значение и **кто следующий**
- Чтобы дойти до третьего — идёшь: первый → второй → третий  
- Вставить/перецепить ссылку часто дешевле по идее (на практике в Java ArrayList чаще быстрее — но на собесах список обязателен)

Аналогия: не ряд шкафчиков с номерами, а **цепочка людей**, где у каждого в руке записка «следующий — вот тот».

---

## 2. Узел (ListNode)

Один человек в цепочке:

| Поле | Смысл |
|------|--------|
| `val` | число (или любые данные) |
| `next` | ссылка на следующий узел, или `null` если конец |

`null` = «дальше никого нет». Это важно: цикл `while (cur != null)` идёт, пока цепочка не кончилась.

---

## 3. Картинка

Список `1 → 2 → 3`:

```text
 head
  |
  v
┌─────┬────┐    ┌─────┬────┐    ┌─────┬────┐
│  1  │  ●─┼───►│  2  │  ●─┼───►│  3  │null│
└─────┴────┘    └─────┴────┘    └─────┴────┘
  узел A           узел B           узел C
```

- `head` — не «магическое слово», а **переменная-ссылка** на первый узел (A).  
- Из A по `next` попадаешь в B, из B в C.  
- У C `next == null` — конец.

Если потеряешь `head` и нигде больше не хранишь ссылку на A — **весь список потерян** (как потерять начало клубка ниток).

## 4. Связь с тем, что ты уже знаешь

В `BankAccount`:

```text
BankAccount a = ...;
BankAccount b = a;   // b указывает на ТОТ ЖЕ объект
```

В списке то же самое: `next` — такая же ссылка на объект, не «копия узла».  
Перецепить `next` = сказать: «теперь после меня идёт вот этот», не копируя значения вручную по массиву.

---

## 5. Как пройтись по списку (идея)

Нужна дополнительная ссылка «где я сейчас», часто называют `cur` (current):

1. Поставь `cur` на `head`  
2. Пока `cur` не `null`:  
   - посмотри `cur.val`  
   - перейди дальше: `cur = cur.next`  

`head` при этом обычно **не двигают** — иначе потеряешь начало. Двигают копию ссылки (`cur`).

В задании у тебя уже есть `print` — он делает ровно этот обход. Можешь прочитать его глазами как учебник.

## 6. Что такое «развернуть список»

Было:

```text
1 → 2 → 3 → null
```

Нужно:

```text
3 → 2 → 1 → null
```

Меняются не числа в узлах обязательно «перестановкой значений», а **стрелки `next`**:

- у узла `2` раньше `next` смотрел на `3`, должен смотреть на `1`  
- у `1` `next` должен стать `null` (он стал хвостом)  
- новой головой становится бывший хвост `3`

Сложность: если просто сделать `1.next = null`, потеряешь доступ к `2` и `3`, если заранее не сохранил ссылки.  
Поэтому в голове держат несколько «пальцев»: где предыдущий, где текущий, где следующий кусок, который ещё не трогали.

---

## 7. Пустой список и один элемент

- `head == null` — список пустой, разворот = тот же `null`  
- один узел — разворот = он же (стрелку менять некуда)

Имеет смысл помнить на тестах.

---

## 8. Зачем тебе это сейчас

Задача Reverse Linked List проверяет не «хитрую математику», а:
- понимаешь ли ссылки  
- не теряешь ли узлы при перецеплении  
- умеешь ли аккуратно пройти цепочку  

После разворота обычно идут: merge two lists, mid of list, cycle — та же база.
