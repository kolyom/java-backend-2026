# Обход дерева по уровням (BFS)

Глубину ты считал **рекурсией вниз** (DFS).  
Level order — **по этажам**: сначала все узлы уровня 1, потом все уровня 2, …

```text
      3
     / \
    9  20
      /  \
    15    7

результат: [[3], [9, 20], [15, 7]]
```

---

## Очередь, не стек

Идея как «люди в очереди в магазине»:

1. Положи корень в очередь  
2. Пока очередь не пуста:  
   - запомни, **сколько** узлов сейчас в очереди — это размер **текущего уровня**  
   - столько раз: достань узел, запиши `val`, положи в очередь его `left` и `right` (если не null)  
3. Список значений уровня добавь в ответ  

Почему «размер очереди в начале шага»: в очередь уже подмешиваются дети следующего этажа. Если не отсечь длину, смешаются уровни.

## В Java

`Queue<TreeNode>` — обычно `ArrayDeque`.  
`offer` / `poll` (или `add` / `remove`).

Пустой `root` → пустой список списков.
