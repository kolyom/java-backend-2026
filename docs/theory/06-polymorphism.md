# Тема 4 — Полиморфизм (кратко)

## Идея

Одна переменная типа родителя может ссылаться на разные наследники.
При вызове метода срабатывает **реализация того объекта, который реально создали**.

```java
BankAccount a = new SavingsAccount(1, 100_00, 0.05);
a.deposit(10_00); // метод родителя
```

## Зачем

Писать код, который работает с «счётом вообще», а подставлять сберегательный, кредитный и т.д.

## Упражнение

В `SavingsAccount` **переопредели** `print()`:

1. `@Override`
2. Сначала вызови печать родителя: `super.print()`
3. Потом напечатай `annualRate`

В `main` создай переменную типа **`BankAccount`**, но объект **`new SavingsAccount(...)`**.
Вызови `print()` — должны появиться и id/balance, и ставка.

Это и есть полиморфизм + `@Override` на практике.
