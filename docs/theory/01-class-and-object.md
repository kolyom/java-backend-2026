# Тема 1 — Класс и объект

Статус: в работе  
После этой темы: инкапсуляция и конструкторы

## Зачем

Почти весь Java-бэкенд — это объекты: пользователь, счёт, перевод, заказ.  
Класс = чертёж. Объект = конкретная вещь по этому чертежу.

---

## Ликбез

### Класс
Описывает:
- **поля** — данные (состояние)
- **методы** — поведение (что умеет делать)

```java
public class BankAccount {
    Long id;
    Long balanceKopecks; // лучше хранить деньги в копейках (Long), не в double

    void deposit(Long amount) {
        balanceKopecks = balanceKopecks + amount;
    }
}
```

### Объект
Конкретный экземпляр класса. В памяти свой набор полей.

```java
BankAccount a = new BankAccount(); // создали объект
BankAccount b = new BankAccount(); // другой объект, тот же класс

a.id = 1;
a.balanceKopecks = 100_00; // 100 рублей
a.deposit(50_00);

b.id = 2;
b.balanceKopecks = 0;
```

`a` и `b` — разные объекты. Изменение `a` не трогает `b`.

### `new`
Выделяет место под объект и вызывает конструктор (пока неявный пустой).  
Без `new` объекта нет — есть только тип переменной.

### `this` (забегая на шаг)
Внутри метода `this` — «этот конкретный объект».  
Подробнее разберём на теме про конструкторы.

### Ссылка, не «сама коробка»
Переменная `a` хранит **ссылку** на объект, не копию всех полей.

```java
BankAccount x = a;  // x указывает на ТОТ ЖЕ объект, что и a
x.deposit(10_00);   // balance у a тоже вырос
```

## Связь с лабой equals/hashCode

Там было два объекта `BrokenAccountId` с одинаковым `value`.  
Это как два разных «листка» с одним и тем же номером счёта на бумаге:  
объекта два, смысл один. `equals` как раз про смысл.

## Упражнение (сделай в VS Code)

Файл: `labs/oop/BankAccount.java`

Требования (сделай ровно это):

1. Класс `BankAccount` с полями:
   - `Long id`
   - `Long balanceKopecks`
2. Метод `void deposit(Long amount)` — увеличивает баланс на `amount`
3. Метод `boolean withdraw(Long amount)`:
   - если денег хватает — списать и вернуть `true`
   - если нет — ничего не менять, вернуть `false`
4. Метод `void print()` — печатает id и баланс в консоль
5. В `main`:
   - создай два счёта
   - на первый положи 100_00, сними 30_00
   - на второй положи 50_00, попробуй снять 100_00
   - вызови `print()` для обоих

Запуск: Run Java над `main`.

Ожидаемый смысл вывода (формат печати — любой понятный):
- первый счёт: баланс 70_00
- второй: баланс 50_00 (снятие не прошло)
