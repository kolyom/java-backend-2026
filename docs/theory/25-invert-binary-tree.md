# Invert Binary Tree (день 11)

Ты уже умеешь: «если `null` — стоп; иначе спустись влево и вправо».

Сейчас не считаем глубину, а **меняем стрелки**.

---

## Что значит «перевернуть»

У **каждого** узла `left` и `right` меняются местами. Не только у корня — у всего дерева.

```text
было:  2.left = 1,  2.right = 3
стало: 2.left = 3,  2.right = 1
```

И то же для `4`, `7`, …

---

## Порядок мыслей

1. База: пустой узел → нечего менять, верни как есть  
2. На живом узле: сохрани одну ссылку (иначе потеряешь ветку, как в reverse list)  
3. Поменяй `left` и `right`  
4. Рекурсивно инвертируй уже новые поддеревья (или сначала детей, потом swap — оба порядка ок, если не теряешь ссылки)

Это тот же паттерн, что разворот списка: **не потеряй то, на что указывала старая ссылка**.
