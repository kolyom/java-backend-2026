# Слияние двух отсортированных списков — идея

Перед кодом.

## Что дано

Два связных списка, каждый уже отсортирован по возрастанию.
Нужно собрать **один** отсортированный список из всех узлов.

Пример:
```text
list1: 1 → 2 → 4
list2: 1 → 3 → 4
результат: 1 → 1 → 2 → 3 → 4 → 4
```

## Идея (без кода)

Как слияние двух отсортированных очередей людей по росту:
смотришь на двух текущих «первых в очереди» и берёшь **меньшего** в результат, сдвигаешь только эту очередь.

Повторяешь, пока обе не кончатся.
Если одна кончилась раньше — хвост другой просто дописываешь в конец результата.

## Техническая деталь

Часто заводят фальшивый стартовый узел («dummy»), чтобы не мучиться отдельно с первой головой результата. Итоговая голова — `dummy.next`.

Узлы **те же объекты**, что были во входных списках (перецепляешь `next`, не создаёшь новые с теми же числами — так обычно ждут на LeetCode).

Когда идея ясна — пиши в `MergeTwoSortedLists.java`.
