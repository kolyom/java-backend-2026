# Symmetric Tree

Симметрия = **зеркало**: левое поддерево корня отражает правое.

Сравнивать нужно не «левый ребёнок с левым», а крест-накрест:

```text
узел A и узел B — зеркальная пара:
  A.val == B.val
  A.left  зеркалит B.right
  A.right зеркалит B.left
```

Для корня: вызываешь проверку пары `(root.left, root.right)`.

Базы:
- оба `null` → симметрично (пустое зеркало)
- один `null`, другой нет → нет
- значения разные → нет

Дальше — рекурсия на две пары: `(A.left, B.right)` и `(A.right, B.left)`.

Пустой `root` на LeetCode обычно считают `true` (или смотри условие; часто `root == null` → true).
