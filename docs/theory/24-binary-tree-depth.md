# Бинарное дерево — глубина (день 11)

## Узел

Как `ListNode`, но **две** ссылки:

| Поле | Смысл |
|------|--------|
| `val` | значение |
| `left` | левое поддерево (или `null`) |
| `right` | правое поддерево (или `null`) |

`null` = «здесь нет узла» / пустое дерево.

---

## Глубина

Число **узлов** на самом длинном пути от корня до листа.

```text
      3          ← уровень 1
     / \
    9  20        ← уровень 2
      /  \
    15    7      ← уровень 3
```

Ответ **3**.

---

## Рекурсивная идея

Для любого узла:

```text
глубина(узел) =
  если узел == null → 0
  иначе → 1 + max( глубина(left), глубина(right) )
```

Ты спрашиваешь: «насколько глубоко слева? насколько справа?» — берёшь большее и добавляешь себя.

Это тот же приём, что «разбей задачу на подзадачи» — поддеревья независимы.
