# Стратегия: ошибки без копипаста в чат

## Главное правило

Код живёт в файлах репозитория. В чат пишешь только:
- путь к файлу
- одну фразу: `compile` / `review` / `stuck` / `accepted`

Ментор сам читает файл, при необходимости компилирует и отвечает.

## Три уровня проблем (различай их)

| Уровень | Где видно | Что делать |
|--------|-----------|------------|
| **Compile** | красная волна в IDE / `javac` | сначала сам по чеклисту ниже 5 минут |
| **Runtime** | программа упала при запуске | пришли путь + текст exception (одной строкой) |
| **Logic** | LeetCode Wrong Answer / свои тесты | `review` + что ожидал vs что получил |

Compile почти всегда решаешь сам. Logic — разбор с ментором, без спойлеров алгоритма сначала.

## Чеклист compile (прочитай сообщение сверху вниз)

1. **Какой файл и какая строка?** — иди туда глазами.
2. **Что требует компилятор?** Частые:
   - `missing return statement` → не все ветки возвращают значение
   - `incompatible types` → вернул не тот тип (`void` вместо `int[]`, и т.п.)
   - `cannot find symbol` → опечатка в имени / нет import / переменная не в scope
   - `'; already defined` → два раза объявил одно имя
   - `'else' without 'if'` / `; expected` → скобка или точка с запятой
3. **Метод обещал тип X** — каждый `return` и конец метода должны это соблюдать.
4. Поправил → сохрани → подожди, пока красное исчезнет → только потом LeetCode.

## Как писать задачи у нас

```
algorithms/solutions/day-01/
  TwoSum.java
  ValidAnagram.java
  ...
```

Шаблон класса — как на LeetCode (`class Solution`), плюс `main` с 1–2 своими примерами, чтобы ловить logic до сайта.

## Команды ментору (копируй как есть)

- `compile algorithms/solutions/day-01/TwoSum.java` — проверь, собирается ли
- `review algorithms/solutions/day-01/TwoSum.java` — логика, без готового решения
- `stuck TwoSum` — сижу >20 мин, дай наводящий вопрос
- `accepted TwoSum` — кратко: подход + Time/Space в `algorithms/day-01.md`

## Динамически — да

Пока файл в этом проекте открыт или лежит в `algorithms/`:
1. Ты сохраняешь файл.
2. Пишешь `compile` или `review` + путь.
3. Ментор смотрит код/диагностики и отвечает точечно.

Не нужно каждый раз вставлять весь класс в чат.
