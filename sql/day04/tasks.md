Сначала выполни `seed.sql`. Ответы пиши в `answers.sql` (под каждым номером свой запрос).

Когда всё сделаешь — `done` в чат (SQL-блок). `pick N` — подсказка по задаче N словами.

---

## 1. SELECT
Выведи `name` и `city` всех пользователей.

## 2. WHERE
Выведи пользователей из Москвы.

## 3. ORDER BY
Выведи все заказы, сортировка по `amount` по убыванию.

## 4. INNER JOIN
Выведи `name` пользователя и `amount` заказа для всех заказов (склейка users + orders).

## 5. LEFT JOIN
Выведи `name` и `amount` так, чтобы пользователи **без** заказов тоже были в результате (`amount` будет NULL).

## 6. GROUP BY
По каждому `user_id` посчитай число заказов (`COUNT`) и сумму `amount` (`SUM`).

## 7. JOIN + GROUP BY
Выведи `name` и сумму всех его заказов. Только пользователи, у которых сумма **больше 100**.

(Подсказка: `HAVING`, не WHERE по сумме.)
