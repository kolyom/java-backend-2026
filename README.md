# Java Backend 2026

Подготовка к стажировке Java/Spring backend (Россия).
Цель: пройти отбор в Т-Банк / VK / Яндекс / Wildberries / Иннотех и параллельно AQA на Java.

## Структура

```
algorithms/          # ежедневные задачи (LeetCode / Яндекс Тренировки)
labs/                # лабы по Java Core (запускай в VS Code)
wallet-service/      # пет-проект для портфолио
docs/
  learning-plan.md   # план на месяц
  vscode-setup.md    # как открыть проект в VS Code
  day-log/           # дневник: что сделал, что застряло
```

**Код и запуск — в VS Code.** Менторство — в чате Cursor. Инструкция: `docs/vscode-setup.md`.

## Правила работы с ментором

1. Каждый день — короткое сообщение: что сделал, что не понял, ссылка на код.
2. Код пишешь ты. ИИ — только для объяснений и разбора ошибок, не для генерации решений.
3. Алгоритмы — 1 час в день, без исключений.
4. Definition of Done на день закрываем вместе.

## Стек пет-проекта

Java 21 · Spring Boot 3 · PostgreSQL · Liquibase · Docker · JUnit 5 · Nginx
